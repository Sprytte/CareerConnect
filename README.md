## Project Overview

We plan to build a campus event and ticketing application that helps students discover events and obtain tickets. The application will support three user roles: attendees, event organizers, and administrators.

Our initial understanding is that attendees will browse events and obtain tickets, organizers will manage their events, and administrators will oversee the platform. The exact permissions and required features will be confirmed against the official project specification.

## First Proposed Feature: Browse Upcoming Events

**User story ID:** US-01  
**Status:** Draft — pending team review  
**GitHub Issue:** [Add issue URL after creation]  
**Owner:** [Team member]

> As a student, I want to browse upcoming campus events and view their details so that I can decide which events I want to attend.

### Acceptance Criteria

- When upcoming events exist, the student can view a list showing each event's title, date, and location.
- When the student selects an event, they can view its title, description, date and time, location, organizer, and ticket price or free-entry status.
- Events whose scheduled end time has passed are excluded from the upcoming-events list.
- When no upcoming events exist, the application displays a clear message stating that no upcoming events are available.
