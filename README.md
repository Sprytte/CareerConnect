## Project Overview

CareerConnect is a web-based job search and application tracking platform designed to help job seekers organize and manage their job search activities in one place.

The platform will allow job seekers to create profiles, upload and manage resumes, search for job opportunities, submit applications, save jobs, and track the status of their applications.

Recruiters will be able to create and manage job postings and interact with applicants through the platform.

The goal of CareerConnect is to centralize the job-search process and make it easier for users to manage their career development activities.

## Problem

Job seekers often use several different websites, documents, and tools to search for jobs and track their applications. This can make it difficult to remember where they applied, the current status of each application, and important deadlines.

CareerConnect aims to solve this problem by providing a single platform where users can search for opportunities and keep track of their applications.

## Proposed Solution

CareerConnect will provide a centralized web application where job seekers can:

- Create and manage an account
- Maintain a user profile
- Upload and manage resumes
- Search and filter job opportunities
- Submit job applications
- Track application status
- View application history
- Save favourite jobs
- Receive notifications and reminders

Recruiters will be able to create and manage job postings.

The application will also include at least one Generative AI feature as required by the project specification.

## Team Workflow

Each team member will work on assigned GitHub Issues using separate branches.

A typical workflow will be:

1. Update the local `main` branch.
2. Create a feature branch.
3. Implement the assigned task.
4. Commit the changes.
5. Push the feature branch to GitHub.
6. Create a pull request.
7. Have another team member review the pull request.
8. Merge approved changes into `main`.

## Branching Strategy

The `main` branch will contain the stable version of the project.

Feature development will be completed using separate branches such as:

- `feature/user-registration`
- `feature/login`
- `feature/user-profile`
- `feature/resume-upload`
