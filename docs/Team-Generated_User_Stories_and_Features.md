# Team-Generated User Stories and Features

## US-11 View Applicants
As a recruiter, I want to be able to view the applications on my job posting so that I can then have the option to reject, setup interview, or make an offer to each applicant.
- Task 11.1: View created job postings 
- Task 11.2: Update application of applicant
- Task 11.3: Build UI to view and update application

## US-12 Deadline notifications
As a job seeker, I want to receive a notification when the deadline of one of my saved/favourited jobs is coming up so that I won't accidentally miss it.
- Task 12.1: Send notifications when deadline is approaching

## US-13 Notifications on application status update
As a job seeker, I want to receive an email (gmail) whenever the status of one of my applications gets updated so that I can stay up-to-date and not miss deadlines.
- Task 13.1: Send notifications when application status updated

## US-14 Edit or withdraw application
As a job seeker, I want to be able to edit or withdraw any of my applications (that haven't passed the deadline) so that I have the option to change my mind
- Task 14.1: Implement editing and removal of application
- Task 14.2: Allow users to edit and withdraw their application

## US-15 Add notes to job application
As a job seeker, I want to be able to add notes when saving/applying to a job so that I can keep track of important details and not forget them.
- Task 15.1: Add notes field to job application
- Task 15.2: Add prompt for notes when applying
